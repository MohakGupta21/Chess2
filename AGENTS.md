# The Game of Chess

## Business Requirement

this project is building a chess game architecture.
Key Features:-
-A user can sign in
-When signed in, the user can play chess games
-The chess board appears
-The user can play chess with the computer.

-The computer knows how to play chess very well.

## Limitations

For the MVP, there should be only two pages one is the sign in page and the other is the chess board page. Assigning black or white to the user is random.
